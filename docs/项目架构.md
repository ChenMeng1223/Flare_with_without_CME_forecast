## 当前核心数据流

`data/raw/events.xlsx` → `scripts/c1_add_event_id_to_events_xlsx.py` → `scripts/a*.py` 下载 → `scripts/b*.py` / `b_batch_process_images(correct_version_with_gong).py` 生成 PNG → `scripts/c2_generate_json_with_fake_bboxes.py` / `c3_annotate_bboxes_gui(correct_version).py` 维护 `bboxes.json` → `scripts/d_create_hdf5_dataset.py` + `data/hdf5_creator.py` 构建 `data/Solar_Flares_CME_dataset.h5` → `data/hdf5_reader.py` / `data/dataset.py` 生成训练窗口 → `models/multimodal_transformer.py` 完成多任务预测。
